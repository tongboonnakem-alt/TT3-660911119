PROJECT 03 / NETWORK DISCOVERY

automated-lan-device-discovery

ระบบต้นแบบค้นหาอุปกรณ์ในเครือข่าย LAN อัตโนมัติ โดยอ่าน ARP cache ร่วมกับการสแกนด้วย ICMP ping เพื่อรวบรวม IP Address, MAC Address, Hostname และประเภทอุปกรณ์ที่ระบุได้ ส่งผลไปยัง Server และแสดงสถานะผ่านเว็บ Dashboard

  • ค้นหาอุปกรณ์ในเครือข่ายย่อยและตรวจสอบสถานะการตอบสนอง
  • ติดตามค่า RTT และ Packet Loss เพื่อช่วยตรวจสอบปัญหาการเชื่อมต่อ
  • ส่งข้อมูลแบบ Heartbeat ไปยัง FastAPI Server และอัปเดต Dashboard ผ่าน WebSocket
  • บันทึกข้อมูลด้วย SQLite และเก็บผลวัด Uplink ที่ส่งไม่สำเร็จไว้เพื่อส่งซ้ำ
  • มี Simulation Sandbox สำหรับทดสอบผังเครือข่ายและจำลองปัญหาแยกจากระบบจริง

การค้นหาขึ้นอยู่กับขอบเขตเครือข่ายย่อยและการอนุญาตให้ตอบสนองของอุปกรณ์ ตัว Agent ทดสอบบนคอมพิวเตอร์และรองรับการนำไปใช้บน Raspberry Pi
