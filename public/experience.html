Routing & Switching

  • Configure Switching ใน Lab Environment เช่น VLAN, Trunk และ Access Port
  • Configure Static Routing เพื่อเชื่อมต่อหลายเครือข่าย
  • Configure Inter-VLAN Routing และ Default Gateway

Network Devices & Security

  • ใช้งาน Router, Switch และ Firewall
  • Configure Firewall Policy เบื้องต้น (Allow / Deny)
  • Configure NAT (SNAT / DNAT) และ Port Forwarding

Operating System & Networking Tools

  • ใช้งาน Ubuntu Linux ผ่าน Terminal
  • Deploy และบริหาร Web Server บน Ubuntu Linux
  • ใช้ ping, traceroute, ip addr, netstat และ ss
  • ตรวจสอบ Network Log เพื่อ Troubleshoot ปัญหาเบื้องต้น

Monitoring & Troubleshooting

  • เฝ้าติดตามระบบเครือข่ายและ Server
  • วิเคราะห์ปัญหา Network / Server / Application
  • ตรวจสอบ ICMP, Latency และ Packet Loss
